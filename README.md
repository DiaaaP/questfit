# QuestFit

QuestFit — игровой фитнес-трекер: дневные квесты, уровни и XP, командные рейды, недельная активность и спортивная арена.

Живая версия: [diaaap.github.io/questfit](https://diaaap.github.io/questfit/)

## Возможности

- регистрация и вход;
- сохранение прогресса пользователя;
- выполнение ежедневных квестов и начисление XP;
- журнал тренировок с пятью типами активности;
- недельная цель, сводные метрики, достижения и городской рейтинг;
- редактирование имени, цели, города и настроек уведомлений;
- создание команды и вступление по коду приглашения;
- состав команды, личные вклады в рейд, передача лидерства и исключение участников;
- арена с маршрутом и записью на событие;
- админ-панель с пользователями, редактором квестов и соревнований;
- адаптивный интерфейс для компьютеров и мобильных устройств.

На GitHub Pages приложение работает в демонстрационном режиме и сохраняет аккаунт, квесты, тренировки и настройки в `localStorage`. В полнофункциональном режиме те же сценарии используют API и Cloudflare D1.

## Структура

- `frontend/` — интерфейс и стили QuestFit;
- `backend/` — бизнес-логика авторизации и активности;
- `app/` — страницы и API-маршруты;
- `db/`, `drizzle/` — схема и миграции базы данных.

## API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `POST` | `/api/auth/register` | регистрация пользователя |
| `POST` | `/api/auth/login` | вход и создание сессии |
| `GET` | `/api/auth/session` | проверка текущей сессии |
| `GET/POST` | `/api/activity` | квесты и участие в событии |
| `GET` | `/api/dashboard` | агрегированная аналитика пользователя |
| `GET/POST/DELETE` | `/api/workouts` | история тренировок |
| `PATCH` | `/api/profile` | профиль и недельная цель |
| `GET/POST` | `/api/team` | создание команды, вступление, вклад, выход и состав |
| `GET/POST` | `/api/admin` | пользователи, квесты и соревнования для владельца |

В серверном режиме админ-панель доступна первому зарегистрированному пользователю (`id = 1`). На GitHub Pages включён демонстрационный режим управления с локальными данными.

## План учебной разработки на 5 недель

1. Исследование задачи, прототип в Figma, дизайн-система, структура React-приложения и адаптивный каркас.
2. Регистрация, вход, сессии, схема D1, миграции и ежедневные квесты с XP.
3. Журнал тренировок, формы с валидацией, расчёт статистики, недельная цель и достижения.
4. Командный рейд, арена, регистрация на событие, рейтинг города и уведомления.
5. Мобильная версия, состояния ошибок и загрузки, доступность, тестовые сборки, GitHub Pages и документация.

Такое разбиение можно использовать как календарный план и основу для отчёта: каждый этап даёт отдельный проверяемый результат во фронтенде, API и базе данных.

## Локальный запуск

Нужен Node.js 22.13 или новее и pnpm.

```bash
pnpm install
pnpm dev
```

После запуска откройте `http://127.0.0.1:5173/`.

## Проверка сборки

```bash
pnpm exec tsc --noEmit
pnpm build
pnpm pages:build
```

## Технологии

React, TypeScript, Vinext, Cloudflare Workers/D1, Drizzle ORM и Radix UI.
