# QuestFit

QuestFit — игровой фитнес-трекер: дневные квесты, уровни и XP, командные рейды, недельная активность и спортивная арена.

Живая версия: [questfit-arena.siren228.chatgpt.site](https://questfit-arena.siren228.chatgpt.site/)

## Возможности

- регистрация и вход;
- сохранение прогресса пользователя;
- выполнение ежедневных квестов и начисление XP;
- командный рейд с общим прогрессом;
- арена с маршрутом и записью на событие;
- адаптивный интерфейс для компьютеров и мобильных устройств.

## Структура

- `frontend/` — интерфейс и стили QuestFit;
- `backend/` — бизнес-логика авторизации и активности;
- `app/` — страницы и API-маршруты;
- `db/`, `drizzle/` — схема и миграции базы данных.

## Локальный запуск

Нужен Node.js 22.13 или новее и pnpm.

```bash
pnpm install
pnpm dev
```

После запуска откройте `http://127.0.0.1:5173/`.

## Проверка сборки

```bash
pnpm build
```

## Технологии

React, TypeScript, Vinext, Cloudflare Workers/D1, Drizzle ORM и Radix UI.
